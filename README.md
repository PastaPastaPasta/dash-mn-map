# dash-mn-map (moved)

The Dash masternode map now lives at **https://nodes.dashhq.org/map**, as part of Dash Nodes
(network crawl, masternode list and map in one site, with live data instead of a daily snapshot).

This repository only serves redirects for the old addresses:

- `map.dashhq.org` (GitHub Pages): `index.html` and `404.html` redirect with a meta refresh.
- `map.thepasta.org` (Cloudflare Pages): `_redirects` sends a 301 for every path.
